# 🌟 EdTech 

EdTech is a **fully designed and developed web project** that promotes a youth-led initiative empowering girls through **STEM education, workshops, and community programs**.  
It provides a **modern, responsive, and user-friendly interface** to showcase the organization’s mission, programs, events, and impact 🚀

## ✨ Features

- 🎨 **Custom UI Design**  
  Entire website designed and developed from scratch with a modern and accessible interface.

- 📚 **Informative Sections**  
  Detailed presentation of STEM programs, workshops, events, and organizational impact.

- 🌍 **Community Focused**  
  Showcases outreach programs and opportunities for girls in underserved areas.

- 📱 **Responsive Design**  
  Optimized for mobile, tablet, and desktop devices for seamless browsing.

- ⚡ **Performance Optimized**  
  Fast load times and smooth navigation for an enhanced user experience.

- 🧠 **Educational Focus**  
  Provides clear and inspiring content to encourage girls to explore STEM subjects.
